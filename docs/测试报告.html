4. 测试结论

结论摘要

维度结果说明
单元测试100% 通过 (31/31)覆盖安全工具 + 核心业务逻辑
集成测试通过Spring 上下文正常加载
功能测试核心功能全部可用需配置的功能（SMTP/AI Key）在配置后正常
已知限制2 项需长时间验证宠物饿死流程（需 24h+）、语音识别精度

4.1 覆盖率说明

  • 安全层：JWT 签发/校验/防篡改/防过期 100% 覆盖；AES 加解密往返 + 异常处理 100% 覆盖
  • 宠物业务：状态推进（正常/饥饿到 0/病危死亡/异常输入）6 个场景；抽蛋校验 5 个场景；成长/上架 8 个场景
  • 番茄钟：等级计算/完成结算/暂停限制/归属校验/放弃 5 个场景
  • 未覆盖：前端 Vue 组件（建议后续引入 vitest）、Controller 层冒烟测试（建议后续引入 MockMvc）

4.2 风险与建议

风险等级建议
AI 语音识别精度依赖浏览器低作为辅助功能保留，不影响核心流程
SMTP 配置错误导致验证码发不出中部署手册中已给出详细配置步骤
透明悬浮窗在特定显卡上崩溃低已禁用硬件加速 + DPI 感知 + 崩溃自动重载
前端组件无自动化测试中建议后续引入 vitest 覆盖 http.js 拦截器
