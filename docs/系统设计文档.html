AI 宠物助手 — 系统设计文档

文档版本：V1.0  |  编写日期：2026-08-17
技术栈：Java 21 + Spring Boot 3 + MyBatis-Plus + Vue 3 + Electron + MySQL 8

1. 系统架构

1.1 架构总览

系统采用三层架构：Electron 桌面客户端（前端）+ Spring Boot REST API（后端）+ MySQL 数据库。Electron 主进程负责桌面级能力（悬浮窗、系统通知、文件操作、摄像头权限），Vue 渲染进程负责 UI 交互，后端提供全部业务逻辑。

1.2 技术选型

层技术选型理由
桌面壳Electron跨平台、支持透明悬浮窗、系统通知、文件操作
前端框架Vue 3 + ViteComposition API 简洁、Vite 热更新快
UI 风格自定义 CSS（8-bit 像素风）不依赖 UI 库，完全自控渲染效果
后端框架Spring Boot 3Java 生态成熟、自动配置、内嵌 Tomcat
ORMMyBatis-PlusLambdaQueryWrapper 类型安全、自动 CRUD
数据库MySQL 8关系型存储、事务支持、逻辑删除
认证JWT (jjwt 0.12)无状态、前后端分离友好
加密AES (Hutool)API Key 对称加密存储
工具库Hutool / Lombok减少样板代码、RandomUtil/JSONUtil 常用
测试JUnit 5 + Mockito + H2标准 Java 测试栈、内存数据库不依赖 MySQL

3.7 设计模式与关键决策

决策方案理由
饥饿计算懒计算（访问时按时间差一次性结算）不需要定时任务轮询，减少数据库压力
宠物死亡病危 24h 缓冲 + 墓碑 + 反思答题给用户补救机会，同时让"死亡"有教育意义
抽蛋稀有度70% / 25% / 5%传说稀有但不绝望，普通也能养出感情
配种冷却雄性 3 天冷却防止刷配种
番茄钟奖励1 币/分钟20 分钟 = 20 币，1 小时 = 60 币，激励长专注
应用感知默认关 + 仅进程名 + 7 天清理隐私红线，用户知情同意
透明悬浮窗禁用硬件加速 + DPI 感知规避显卡崩溃，同时避免高 DPI 模糊
