2. 数据库初始化

数据库就像宠物的"档案柜"，所有用户、宠物、日程数据都存在这里。

1登录 MySQL 
mysql -u root -p
2创建数据库 
CREATE DATABASE pet_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE pet_db;
3导入建表脚本

在 MySQL 命令行中执行项目目录下的 SQL 脚本（按文件名顺序执行）：

-- 先执行基础建表
source c:/Users/HP/Desktop/pet/pet-backend/src/main/resources/sql/schema.sql;
-- 再按 M3 → M4 → ... → M13 的顺序执行迁移脚本
source c:/Users/HP/Desktop/pet/pet-backend/src/main/resources/sql/m3.sql;
source c:/Users/HP/Desktop/pet/pet-backend/src/main/resources/sql/m4.sql;
-- ... 依次执行到 m13.sql
注意：迁移脚本必须按编号顺序执行，后面的脚本依赖前面的表结构。
4验证 
SHOW TABLES;

3. 后端配置与启动

3.1 数据库连接配置

打开 pet-backend/src/main/resources/application.yml，修改数据库连接信息：

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/pet_db?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password:

3.2 SMTP 邮箱配置（注册验证码用）

注册时系统需要发验证码邮件。就像寄信需要知道邮局地址和寄信人信息，这里需要配 4 个值：

spring:
  mail:
    # 1) host:QQ邮箱用 smtp.qq.com;163邮箱用 smtp.163.com;Outlook用 smtp.office365.com
    host: smtp.qq.com
    # 2) port:SSL 加密端口一般用 465
    port: 465
    # 3) username:你的邮箱地址，如 12345@qq.com
    username: <你的邮箱@qq.com>
    # 4) password:邮箱「授权码」，不是登录密码！
    #    QQ邮箱 → 设置 → 账户 → 开启 SMTP 服务 → 生成授权码
    password: <你的邮箱授权码>
    # 5) from:发件人，一般和 username 一样
    from: <你的邮箱@qq.com>
安全红线：授权码是敏感信息，不要发到聊天里，也不要提交到 Git。如果项目要上传 GitHub，把 application.yml 加入 .gitignore。

3.3 启动后端

1用 IDEA 打开后端项目

File → Open → 选择 c:\Users\HP\Desktop\pet\pet-backend 文件夹 → 信任项目

2等待 Maven 下载依赖

打开后 IDEA 右下角会显示"正在导入 Maven 依赖"，等进度条走完（第一次可能需要 3-5 分钟）。

3运行启动类

在 IDEA 左侧找到 PetApplication.java（路径：src/main/java/com/pet/PetApplication.java），右键 → Run。

看到控制台输出 Started PetApplication in x.xxx seconds 就说明启动成功了。

浏览器打开 http://localhost:8080/api/health，看到 JSON 返回就说明后端正常。

5. 日常使用指南

5.1 第一次使用

  1. 注册账号：输入用户名、密码、邮箱 → 获取验证码 → 填密保问题和答案 → 注册。
    第一个注册的用户自动成为管理员。
  2. 登录：用刚注册的账号登录。
  3. 抽蛋领养：点击"抽蛋"按钮，给宠物起个名字（最多 12 字，只能起一次！），随机获得一只宠物。
  4. 喂食：新宠物送 10 条小鱼干。去"商店"买更多食物，在"宠物"面板喂食。

6. 常见问题（FAQ）

Q1: 启动后端报"Access denied for user 'root'"

原因：数据库密码不对。

解决：检查 application.yml 里的 spring.datasource.password 是否和你安装 MySQL 时设的密码一致。

Q2: 注册时收不到验证码邮件

原因：SMTP 配置不对，或授权码错误。

解决：

  1. 确认 application.yml 中的 host 和你的邮箱匹配（QQ 邮箱用 smtp.qq.com）
  2. 确认 password 填的是授权码而不是邮箱登录密码
  3. QQ 邮箱获取授权码：登录 QQ 邮箱 → 设置 → 账户 → POP3/SMTP 服务 → 开启 → 生成授权码
  4. 修改配置后重启后端

Q3: 前端界面模糊/图标看不清

原因：Windows 高 DPI 缩放（125%/150%）+ 禁用硬件加速导致软件渲染模糊。

已修复：main.js 中已添加 high-dpi-support 和 force-device-scale-factor 开关。如果仍然模糊，尝试：

  1. Windows 设置 → 显示 → 缩放设为 100%
  2. 右键 Electron 快捷方式 → 属性 → 兼容性 → 更改高 DPI 设置 → 勾选"替代高 DPI 缩放行为" → 选"应用程序"

Q4: 悬浮宠物不显示

解决：右键系统托盘图标（右下角）→ "显示/隐藏悬浮宠物"。

Q5: 摄像头打不开

原因：Electron 默认拒绝摄像头权限。

已修复：main.js 中已配置 setPermissionRequestHandler 放行 media 权限。如果仍不行，检查 Windows 隐私设置中是否允许应用使用摄像头。

Q6: AI 对话不回复

原因：未配置 API Key 或 Key 无效。

解决：设置面板 → 配置服务商 Key → 确认 Key 有效（去服务商官网查看额度/余额）。

Q7: 端口被占用（8080 或 5173）

解决：命令行执行 netstat -ano | findstr :8080 找到占用进程的 PID，然后 taskkill /PID xxx /F 结束它。

Q8: 后端启动报"Table 'pet_db.xxx' doesn't exist"

原因：SQL 脚本没有全部执行。

解决：按顺序执行 schema.sql 和所有 m3-m13.sql 迁移脚本。
