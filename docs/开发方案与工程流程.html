3 工程流程

采用迭代式开发，每批次独立走完"方案确认 → 开发 → 测试 → 验收"闭环。

每批次的具体执行步骤

1
方案设计

我分析需求 → 输出该批次的详细方案（改哪些文件、怎么改、预计工作量）

2
人工确认

你审阅方案 → 确认或提修改意见 → 确认后我才动手写代码

3
分步开发

按功能点逐个实现，每完成一个功能点提交一次，保持可回溯

4
自主测试验证

后端跑 Maven 单测 → 前端跑 Vite 构建 → 启动服务做接口冒烟 → 截图展示

5
用户验收

展示修复效果 → 你确认通过 → 进入下一批次；不通过则回退修复

5 产品定位（人工确认）

定位：学习陪伴型桌面宠物
学生/自学者打开电脑学习时，有一只像素宠物在桌面上陪着你，用番茄钟帮你专注，用日程帮你规划，偶尔跟你说话鼓励你，学完了可以跟它玩一会儿放松。

基于此定位，功能分三个圈层：核心圈（宠物+番茄钟+日程+AI对话+悬浮窗）、增值圈（主题+音效+后院繁育+桌面整理）、砍掉圈（社交/好友/配种市场/摄像头/墓地/托管所/应用感知）。

7 开发方案（三批次）

批次一：缺陷修复 + 技术债 + 砍掉无用功能（预计 2-3 天）

  • 修复 D-15：番茄钟自定义时长修改后需重新选择下拉项 → PomodoroPanel.vue
  • 修复 D-14：管理员总测试增加写操作测试（砍掉AI调用测试，API未配置） → AdminConsole.vue
  • 修复 D-13：播放器 UI + 管理员导入音乐 → SettingPanel.vue / AdminConsole.vue / soundStore.js
  • 清理 T-02：http.js 写死 localhost → src/api/http.js
  • 清理 T-04：AdminPanel 测试重复项 → AdminPanel.vue
  • 清理 T-05：LoginView banVisible 清除 → LoginView.vue
  • 砍掉前端：FriendPanel / InboxPanel / SocialPanel 组件移出导航
  • 砍掉前端：GraveyardPanel / HatchlingPanel 移出导航
  • 砍掉前端：CameraPanel 移出导航
  • 砍掉后端：FriendController / InboxController / BlacklistController / ReportController 接口不删但不再被前端调用
  • 自主测试 + 验收

批次二：核心交互体验（预计 3-4 天）

现状说明：管理员API配置、音色管理、抽宠、聊天界面、气泡设置等基础功能已实现，本批次重点优化悬浮窗体验和气泡人感。

  • 悬浮窗布局重设计 — 宠物大小/位置/计时器配比优化，去掉表盘样式，改为清爽文字倒计时
  • 悬浮窗闪烁优化 — 调研硬件加速+透明窗口方案，减少闪烁和模糊
  • 悬浮窗启动控制 — 设置页开关 + 主界面启动按钮 + 首次启动默认打开
  • 悬浮窗对话增强 — 右键弹出输入框，文字/语音对话（类QQ宠物桌面互动）
  • 气泡库扩充 — 新增 50+ 条台词，增加人感（按场景/心情/行为细分）
  • 点击宠物气泡 — 悬浮窗点击宠物也触发说话气泡
  • 宠物形象一致性 — 主界面/悬浮窗/聊天头像统一使用像素渲染
  • 图片显示验证 — 检查所有场景图片路径，确保正常加载

批次三：UI/UX 大改（预计 5-8 天）

  • 三种小屋主题 + 昼夜+季节+游戏内年时间 + 开关灯（三种独立音效）
  • 房间比例调整 + 三种风格独立不杂交
  • 所有按钮添加声音（接入声音目录素材）
  • 播放器 + 管理员导入音乐 + 音量拖动条（衔接批次一 D-13）
  • 番茄钟逻辑修复（暂停/继续/自动完成/多次暂停）
  • 番茄钟橙色按钮颜色溢出修复
  • 番茄钟命名 + 日程四种优先级分区 + 图表类型切换（对标番茄Todo）
  • 番茄钟完成音效 + 宠物恭喜提示（主界面+悬浮窗）
  • 右下角番茄钟完成提醒声音
  • 后院繁育系统（替代配种市场，单机培育后代）
  • 桌面整理修复
  • 管理员后台精简（用户管理+API配置+气泡库+音乐导入）
