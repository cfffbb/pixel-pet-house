1. 引言

1.1 编写目的

定义 Pet（AI 桌面宠物）系统当前基线版本的功能与非功能需求，作为开发、测试、验收的依据。本文档与代码同步，版本号跟随迭代更新。

1.2 项目背景

将「桌面电子宠物」与「学习陪伴工具」结合：宠物在桌面上陪伴用户，通过日程管理、番茄钟、桌面整理等功能帮助养成良好习惯。宠物会饥饿、生病、死亡，也会因陪伴而开心——情感连接让工具不再冷冰冰。

1.3 系统范围

Electron 桌面应用（Vue 3 + Electron）+ Spring Boot REST API + MySQL。已实现 13 大功能模块、23 个 Controller、16 个 Vue 面板、26 张数据库表。

1.4 术语

术语说明
JWT用户身份认证令牌，7 天过期
懒计算饥饿度不实时轮询，访问时按时间差一次性结算
抽蛋随机获得宠物，稀有度 70%/25%/5%
反思答题宠物死亡后需答 2 道开放题（每题≥10字）才能重新抽蛋

2. 总体描述

2.1 产品概述

用户安装 Electron 应用后注册/登录，抽取一只像素风宠物。宠物以悬浮窗常驻桌面，陪伴学习工作。通过主控窗口管理日程、开启番茄钟、整理桌面、与好友互动、与 AI 聊天。宠物会因饥饿而病危甚至死亡，死亡后需反思答题才能重新领养。

2.2 用户角色

角色权限获取方式
普通用户宠物养成 + 学习工具 + 社交 + AI 对话注册
管理员普通用户全部权限 + 用户/商品/模式管理 + 举报审核首个注册用户自动成为管理员

2.3 约束

  • 操作系统：Windows 10/11（64 位）
  • 运行环境：Java 21+、MySQL 8+、Node.js 18+
  • AI 对话需用户自配 API Key（14 家服务商可选）
  • 邮箱验证需用户自配 SMTP 授权码
  • 不允许 AI 生成图片素材，仅允许联网搜索现成素材库
  • 最终产品需打包为可安装软件（electron-builder）

4. 功能需求

以下仅描述已实现功能的行为规约。需求编号格式：REQ-模块-序号。

4.1 用户认证（REQ-AUTH）P0

REQ-AUTH-01 注册：用户名+密码+邮箱 → 发送 6 位验证码（10 分钟过期）→ 输入验证码+密保问答 → 注册成功。首用户自动 ADMIN。密码 bcrypt 哈希。
REQ-AUTH-02 登录：用户名+密码 → 返回 JWT（7 天过期），前端存 localStorage 并同步 Electron 主进程。
REQ-AUTH-03 找回密码：密保问题验证 → 重置密码。

4.2 宠物养成（REQ-PET）P0

REQ-PET-01 抽蛋：一生一次；稀有度 70% NORMAL / 25% RARE / 5% LEGEND；随机性别（50/50）、性格（5 种）、亚种。管理员可指定种类。新宠物送 10 条小鱼干。
REQ-PET-02 状态推进（懒计算）：饥饿度按 100 / (基准天数×24×性格系数) 下降，保底≥2 天。降到 0→病危；病危 24h 未喂食→死亡+立墓碑。
REQ-PET-03 性格系数：高冷×0.8 / 粘人×1.1 / 贪吃×1.5 / 活泼·傲娇×1.0。
REQ-PET-04 成长阶段：幼年(<1天)→少年(<3天)→成年(<60天)→老年(≥60天)。出生≥3 天成熟（可上架配种）。
REQ-PET-05 玩耍：10 种模式（抚摸/跑步/学习/玩球/散步/听音乐/跳舞/捉迷藏/晒太阳/扑蝶），影响心情/饥饿/经验。每天最多 5 次。
REQ-PET-06 每日行为事件：30% 概率，暖心+5 或破坏-5 心情，每天最多 1 次。
REQ-PET-07 改名：名字只能起一次，不允许更改（总抛异常）。

4.3 商店与喂食（REQ-SHOP）P0

REQ-SHOP-01 商店：FOOD/TOY 两类物品，可按宠物种类过滤、等级锁定。管理员可新增物品。
REQ-SHOP-02 购买：扣游戏币；管理员无限币。
REQ-SHOP-03 喂食：消耗背包食物，恢复饥饿度+心情；病危状态喂食可救回。

4.4 死亡与反思（REQ-DEATH）P1

REQ-DEATH-01 墓碑：宠物死亡后自动创建（名字/种类/性格/寿命天数）。
REQ-DEATH-02 反思答题：2 道开放式题（每题≥10 字），通过后才能重新抽蛋。

4.5 配种与繁殖（REQ-BREED）P1

REQ-BREED-01 上架：雄性+活着+出生≥3 天+非冷却。管理员可无视成熟要求。
REQ-BREED-02 配种：发起方付 10 币→对方接受后双方各扣 10 币→雄性 3 天冷却。
REQ-BREED-03 产崽：雌性怀孕 3 天→每胎 3-5 只→10% 概率夭折。
REQ-BREED-04 幼崽托管：5 币/天托管费→需反思答题才能领取→可赠送。

4.6 日程管理（REQ-SCHED）P0

REQ-SCHED-01 CRUD：创建/查看/修改/删除日程，支持标题/时间/优先级/标签/重复。
REQ-SCHED-02 到期提醒：Electron 主进程每分钟轮询→系统通知。10% 概率被宠物卖萌替代。
REQ-SCHED-03 统计：按标签/时间维度（饼图/柱状/时间分布）。

4.7 番茄钟（REQ-POMO）P0

REQ-POMO-01 开始：自定义时长（默认 25 分钟，上限 480），需有活宠。
REQ-POMO-02 暂停/恢复：每轮最多 2 次。
REQ-POMO-03 完成：专注分钟×1 币。等级=累计分钟/1200，最高 100 级。
REQ-POMO-04 放弃：0 币。悬浮窗显示倒计时，学习中静音。

4.8 社交互动（REQ-SOCIAL）P1

REQ-SOCIAL-01 好友：搜索用户→发申请→对方收件箱接受/拒绝→双向好友。可删除（双向）。
REQ-SOCIAL-02 收件箱：配种/赠送/好友申请+聊天。支持标记已读/接受/拒绝/删除对话。
REQ-SOCIAL-03 拉黑：拉黑后对方无法发起任何申请。
REQ-SOCIAL-04 举报：提交举报→管理员审核（封禁/驳回）。

4.9 AI 对话（REQ-CHAT）P1

REQ-CHAT-01 14 家服务商（通义/DeepSeek/OpenAI/智谱/Kimi/硅基/星火/百度/混元/MiniMax/阶跃/Groq/Ollama/自定义），每家最多 1 个 Key，AES 加密存储。
REQ-CHAT-02 文字对话：后端转发→AI 回复。保留最近 N 条记忆（管理员配置 N）。
REQ-CHAT-03 语音对话：录音→转文字→AI 回复。

4.10 拍照相册（REQ-PHOTO）P1

REQ-PHOTO-01 拍照：Electron 摄像头权限→拍照→存入当前宠物相册。
REQ-PHOTO-02 相册：按宠物分组+搜索+删除。

4.11 桌面整理（REQ-DESK）P1

REQ-DESK-01 分区规则：按扩展名匹配目标文件夹，首次自动建默认分区。可增删改。
REQ-DESK-02 扫描预览→执行整理（移动文件）→可撤销。

4.12 悬浮宠物（REQ-FLOAT）P0

REQ-FLOAT-01 透明置顶可拖拽窗口。点击弹出菜单（撒娇/喂食/玩耍/学习/测试/隐藏）。
REQ-FLOAT-02 陪伴推送：一天 2-3 次随机文案，系统通知+气泡。学习中静音。
REQ-FLOAT-03 宠物主动邀请：每 45-90 分钟随机，一天最多 3 次。
REQ-FLOAT-04 右键投喂：自动选背包第一种食物。
REQ-FLOAT-05 摄像头手势识别：搓手→宠物转圈（趣味功能，精度有限）。

4.13 应用感知（REQ-MON）P2

REQ-MON-01 默认关闭。用户知情后手动开启（隐私红线）。
REQ-MON-02 每 5 分钟采样前台进程名（不采集内容），40% 概率发陪伴通知。保留 7 天。

4.14 管理员后台（REQ-ADMIN）P1

REQ-ADMIN-01 用户管理：分页/启用禁用/重置密码/删除（逻辑删除）。
REQ-ADMIN-02 商品管理+玩耍模式 CRUD。
REQ-ADMIN-03 举报审核：BLOCK/DISMISS。
REQ-ADMIN-04 数据总览+对话记忆配置+管理员换宠（测试用）。

4.15 用户设置（REQ-SET）P1

REQ-SET-01 AI Key 管理（脱敏展示）。
REQ-SET-02 配种授权开关（默认开）+应用感知开关（默认关）。

5. 非功能需求

5.1 性能

指标要求
API 响应95% 请求 < 200ms（本地）
Electron 内存主+渲染进程 < 300MB
轮询频率日程 1 次/分；陪伴 1 次/30 分；应用采样 1 次/5 分

5.2 安全

  • 密码：bcrypt 哈希，不可逆
  • 认证：JWT 7 天过期
  • API Key：AES 加密存储，前端脱敏
  • SQL 防注入：MyBatis-Plus 参数化查询
  • XSS：Vue 默认转义，不使用 v-html 渲染用户输入
  • 隐私红线：应用感知默认关，仅进程名，7 天清理

5.3 可用性

  • UI 风格：8-bit 像素风，暖色调
  • 图片渲染：像素图 pixelated，照片 auto
  • 高 DPI：Electron 禁用硬件加速 + DPI 感知开关

5.4 可维护性

  • 测试：JUnit 5 + Mockito + H2，31 个单测通过
  • 文档：SRS + 系统设计 + 测试报告 + 部署手册，版本管理可回滚
  • 代码规范：Lombok + MyBatis-Plus + Vue 3 Composition API

5.5 兼容性

  • Windows 10/11（64 位）
  • JDK 21+、MySQL 8+、Node.js 18+
