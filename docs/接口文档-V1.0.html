1. 接口规范

1.1 统一返回格式

所有接口统一返回以下 JSON 格式（Result<T>）：

{
  "code": 200,          // 状态码：200=成功，400=参数错误，401=未登录，403=无权限，500=服务器错误
  "msg": "成功",        // 提示消息
  "data": {}            // 数据载荷，失败时为 null
}

1.2 认证方式

需认证的接口在请求头携带 JWT：

Authorization: Bearer <token>

Token 有效期 7 天，登录成功后返回。

1.3 状态码枚举

码常量说明
200SUCCESS成功
400BAD_REQUEST请求参数错误
401UNAUTHORIZED未登录或登录已过期
403FORBIDDEN没有权限
404NOT_FOUND资源不存在
500ERROR服务器内部错误

1.4 基础信息

项值
Base URLhttp://localhost:8080/api
Content-Typeapplication/json
字符编码UTF-8

2. 接口清单（按模块分组）

2.1 用户认证（AuthController）部分无需认证

方法URL认证说明
POST/auth/register否注册（用户名+密码+邮箱验证码+密保问答）
POST/auth/login否登录，返回 JWT token
POST/auth/send-code否发送邮箱验证码
POST/auth/reset-password否找回密码（密保验证）
GET/auth/me是获取当前用户信息

登录响应示例：

POST /api/auth/login
Request: {"username":"admin1","password":"123456"}
Response: {
  "code": 200,
  "msg": "成功",
  "data": {
    "token": "eyJhbGciOi...",
    "userId": 1,
    "username": "admin1",
    "role": "ADMIN"
  }
}

3. 错误处理

所有异常通过 GlobalExceptionHandler（@RestControllerAdvice）统一处理，返回 Result 格式：

异常类型HTTP 状态code说明
BusinessException200500业务异常（自定义消息）
MethodArgumentNotValidException200400参数校验失败
Exception200500未捕获异常兜底

错误响应示例：

{
  "code": 400,
  "msg": "securityQuestion 密保问题不能为空",
  "data": null
}
